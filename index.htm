01地球・気象

まずは、この星から。

頭の上の大気から、足の下の岩盤まで。天文・気象・地球・地質・鉱物・岩石・宇宙工学など、非常に幅広い分野が対象です。深志高校の科学系部活でもっとも担当範囲が広いと言えます。

  • 天文
  • 気象
  • 地球
  • 地質
  • 鉱物
  • 岩石
  • 宇宙工学

02地質・鉱物・岩石

足もとには、気の遠くなる時間。

地学教室には豊富な標本と、戦前のものを含む古い資料が大量に眠っています。当時の雰囲気が感じられるものもあり、整理はけっこう楽しいですよ！学術的にも価値があります。資料整理は偉業。

  • 立体地形図
  • 鉱物・岩石展示
  • 小旅行
活動内容

03天文

県内有数の、天体ドーム。

直径約5 mのドームに、15cm屈折の「主砲」タカハシ FCT-150。流星群がある時期には学校に泊まり込みで観測をし、昼休みには当番制で毎日、太陽黒点をスケッチしています。

  • 流星群観測会
  • 黒点観測
  • 天体の観望・観測
機材を見る

04宇宙工学

空き缶サイズの、人工衛星。

缶サット Fks-A から Fks-B-II まで。リアクションホイールによる姿勢制御、地上との相互無線通信、太陽光発電。宇宙甲子園缶サット部門 全国大会で技術賞をいただきました！

  • 3軸姿勢制御
  • 自作基板
  • 3Dプリンタ
つくったもの

05コンピュータ

Windows 98、いまも現役。

ドームの計算機は Windows 98 で冷却CCDを動かしています。その一方で、缶サットの地上局アプリやシミュレータ、スマホの中でスタック・ダーク減算・波長感度校正まで完結する分光器「FUKASIS」も自作しています。

「マルチな部活」— ドームの Windows 98 機のスクリーンセーバーを模倣しています。
FUKASIS
